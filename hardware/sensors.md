# Sensor selection and measurement contract

Rates below are proposed feature output rates unless a waveform rate is explicitly stated. Prices are single-quantity USD planning allowances as of 2026-10-06, excluding labor/tax; not live quotes. `TBD` is intentionally unverified. Component accuracy is not guaranteed installed-system accuracy.

| Measurement / component | Range; component accuracy | Supply; interface; output | Rate; allowance | Location / isolation / safety |
|---|---|---|---|---|
| Return temperature / SHT31-DIS breakout | −40…125°C; typical ±0.3°C around room conditions, see curve | 3.3 V; I2C 0x44; °C | 0.5 Hz; $15 | Return plenum away from radiant surfaces; SELV; protect from wetting |
| Supply temperature / second SHT31 | Same; accuracy degrades outside typical region | 3.3 V; I2C 0x45; °C | 0.5 Hz; $15 | Mixed supply air downstream of coil; technician installs duct access |
| Indoor/return humidity / same return SHT31 | 0…100%RH; typical ±2%RH, see operating envelope | Same; %RH | 0.5 Hz; included | Avoid condensate; sensor condensation can invalidate results |
| Supply humidity / same supply SHT31 | Same, high-RH performance and condensation require care | Same; %RH | 0.5 Hz; included | Vapor-protective filter cap; do not place in droplets |
| Outdoor air / DS18B20 probe | −55…125°C; ±0.5°C from −10…85°C | 3–5.5 V, use 3.3 V; powered 1-Wire; °C | 0.2 Hz; $8 | Shaded ventilated shield away from condenser exhaust; insulated probe |
| Filter differential / SDP810-500Pa | ±500 Pa; 3% measured value, 0.1 Pa zero-point accuracy | 2.7–5.5 V, use 3.3 V; I2C; signed Pa | 0.5 Hz; $45 | High/low static taps either side of filter; dry air only |

Installation positions, rates and budget allowances are engineering choices, not manufacturer requirements.

Supply/return temperature errors of ±0.3°C each give a worst-case ±0.6°C difference error under those component conditions, before installation error. Do not resolve marginal faults using only a tiny ΔT shift. Return/supply humidity should be compared as humidity ratio with local pressure and temperature for latent-performance research; RH alone rises when air cools.
